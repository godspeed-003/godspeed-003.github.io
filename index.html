02 — Origin

Why any of this exists

A desktop computer at age five, a Marvel obsession, and one stubborn question: why should a machine need me to keep telling it what to do?

the childhood thread

I had a desktop PC from the age of five. For years it was purely for games. But using it every single day, I kept circling one thought: why does this thing need me? It should do a task on one command, not demand continuous back-and-forth that eats my time.

Learning to code answered it. Code solves problems logically, and I loved dissecting everything by logic. In junior college — deep in my Marvel phase — I wanted my own JARVIS. So I learned Python, read other people's code and blogs, and built one as my CS project: it detected specific words in speech (weather, time, news) and fired the matching function. That was the start of solving problems by coding, logically.

The aim hasn't changed since. Build machines — software models or hardware robots — that hold all the world's knowledge and can do the work that needs doing, specialist or generalist. And I believe getting there needs World Models, not just transformers and LLMs.
